O desafio

Muitos cristãos querem fazer leitura diária da Bíblia, mas enfrentam barreiras reais que acabam quebrando a rotina antes que ela se firme:

  • Apps pesados e lentos — carregam devagar, consomem bateria, exigem internet constante
  • Sem estrutura de leitura — a pessoa abre a Bíblia, não sabe por onde começar e fecha
  • Design poluído — anúncios, notificações irrelevantes, dezenas de features que distraem
  • Sem acesso offline — depender de conexão para ler a Palavra é um impedimento real
  • Isolamento espiritual — dificuldade em compartilhar reflexões e versículos com amigos e família

Insight central: Uma pessoa ocupada não quer o app mais completo. Quer algo que abre rápido, não a distraia, e a ajude a manter uma rotina de leitura consistente — todos os dias, sem atrito.

Como foi construído

1. PWA primeiro — zero atrito para começar

Desenvolvido como Progressive Web App, o app funciona completamente offline após a primeira visita. Service Workers fazem cache inteligente de todo o conteúdo. Instalar é opcional — mas quem instala tem ícone na home, abre instantaneamente e recebe notificações.

2. Firebase — sincronização real sem backend customizado

Firebase Realtime Database sincroniza streak, favoritos, progresso nos planos de leitura e oração em tempo real entre dispositivos. Autenticação via Google torna o login um clique — sem cadastro manual, sem senha para esquecer.

3. Design minimalista — sem ruído, só a Palavra

Zero anúncios. Zero sugestões de "apps similares". Tipografia legível, espaçamento generoso, paleta escura com tema #0a0612. A interface some para que a leitura fique em foco.

4. IA bíblica com Groq — sem custo recorrente

O usuário usa a própria chave Groq gratuita, salva localmente no navegador. Privacidade garantida, custo zero para o desenvolvedor, e ainda assim um assistente competente para explicar passagens e contexto histórico.

5. Arte para Stories — retenção via compartilhamento

Canvas API gera imagens formatadas em 3 proporções (Stories, Feed e Twitter/X). Usuário compartilha versículos nas redes, o app aparece para novos usuários organicamente.

Resultado

Um app que de verdade funciona como ferramenta de devoção pessoal — não um "simulador de religião" ou app de curiosidades, mas algo para quem realmente quer ler a Bíblia todos os dias e precisa de estrutura e leveza para isso.

  • ✅ Usuários mantêm consistência de leitura (streak visível, hábito formado)

  • ✅ Voltam ao app diariamente sem esforço consciente
  • ✅ Exploram temas e passagens com o assistente de IA sem custo
